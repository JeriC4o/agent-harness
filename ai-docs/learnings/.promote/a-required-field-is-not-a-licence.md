id: a-required-field-is-not-a-licence

**Rule:** A field that demands a value does not entitle you to invent one. Where the measurement does not
exist, record that it does not, and never overwrite a measured value with a composed one. If the format
has no spelling for "not measured", that is a defect in the format and fixing the rule alone leaves the
pressure in place.

**Why:** A template with no honest spelling for a missing measurement turns a gap into an awkwardness,
and the pressure peaks exactly where scrutiny is lowest — a handoff written for a reader who cannot check
it against anything. Among the values such a record carries, auditability is not uniform: a fabricated
command or revision is obvious on sight, while a fabricated timestamp is indistinguishable from a real
one, so the least checkable field is the one most in need of measure-then-write. Batching the measurement
into the same call as the write that consumes it guarantees the value is authored before the reading
exists.

**Signal:** A required field whose honest answer is "I did not measure that". A clock or counter read
batched with the write that uses it. A handoff document. Any value you are composing rather than copying
out of output you have read.
