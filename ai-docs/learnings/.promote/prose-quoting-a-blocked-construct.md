**Rule:** Text that quotes a construct an automated guard matches goes in through the editing tool, never
assembled inside a command string. The same holds for a helper script whose body quotes such a construct.

**Why:** A guard that inspects the command string cannot tell a citation from a call, so assembling the
payload there hands it the quotation to match. Writing the record of a refusal is therefore the act most
likely to be refused, since the narrative has to quote what was blocked. A standing instruction to build
prose payloads through the shell — which exists for a real hazard, an apostrophe closing the string and
truncating the payload at a success status — is jointly unsatisfiable with the guard in exactly this
case, and this is the case that recurs. Four incidents in one corpus, each committed while writing up the
one above it.

**Signal:** A payload that quotes a command. Writing up a blocked attempt. A helper script authored inside
a command string. Any text carrying both an apostrophe and a quoted command line. A non-verification
script given a name that a guard's name list would match.
