**Rule:** An ambient directive about which tool to use binds on the first call, orientation reads
included, and it overrides the standing tool preferences written into instruction files. Where such a
directive carries its own exception for work a tool genuinely cannot do, name which half of the work the
exception covers rather than letting it cover the session by default.

**Why:** Every recorded instance is the first call of the task, with every later call compliant: the
directive is read, agreed with, and then the habitual tool is reached for before any work has started.
The first call is the one made while orienting, which is when habit is strongest and when the directive
has been in context for the shortest time. Where standing instructions express the opposite preference
and nothing resolves the conflict, the habit acquires a justification — so the resolution belongs in the
instructions, not in the reader's judgement. Four parties, one branch, each entry naming the one above it.

**Signal:** The first tool call of a task. A directive you have just finished reading and agreed with. Any
instruction file that states a tool preference the directive contradicts.
